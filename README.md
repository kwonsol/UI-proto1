# Scent Vector — 향 취향 시각화 프로토타입

향수를 수치 벡터로 표현하고, 사용자가 쓴 향수 벡터의 **평균(취향 벡터)** 하나만으로 모션 그래픽을 생성하는 결정론적 시스템입니다.
난수를 쓰지 않아 같은 벡터는 같은 시간 t에서 항상 같은 프레임(같은 픽셀)을 만듭니다.

## 실행

빌드 없이 정적 파일로 동작합니다.

```bash
python3 -m http.server 8000   # 또는 npm start
# http://localhost:8000 접속 (index.html을 직접 열어도 동작)
npm test                      # 결정론·단조성 테스트 (Node 18+)
```

## 벡터 정의

| 성분 | 범위 | 의미 |
|---|---|---|
| `f = [플로럴, 우디, 오리엔탈, 시트러스, 그린/아쿠아틱]` | 각 0–1, 합 = 1 | 계열 비중 |
| `c` | 0–1 | 농도 (오 드 코롱 0 · EdT ⅓ · EdP ⅔ · 퍼퓸 1) |
| `l` | 0–1 | 지속력 |
| `s` | 0–1 | 실라주(확산력) |

취향 벡터 = 사용한 향수 벡터들의 산술 평균 (`ScentEngine.meanVector`). 계열 비중은 평균해도 합이 1로 유지됩니다.

## 계열별 모션

각 계열은 고유한 모션 레이어를 가집니다. 취향 벡터의 구성 비율에 따라 레이어가 겹치며, 가장 높은 계열이 가장 진하게(불투명도 100%) 맨 위에 그려집니다.

| 계열 | 모션 | 모양 | 팔레트 (바탕 / 선) |
|---|---|---|---|
| 우디 | 나뭇결 섬유 | 흐름장을 따라 휘날리는 외곽선 섬유 다발 (참고 이미지 1) | 카키 / 크림·다크브라운 외곽선 |
| 플로럴 | 꽃잎 부채 | 가는 선이 부채꼴로 퍼지는 조개껍질형 꽃잎, 숨 쉬듯 회전 (참고 이미지 2) | 라벤더 / 연핑크 |
| 시트러스 | 과즙 방울 | 목으로 이어졌다 끊어지는 메타볼 방울, 가장자리 옐로우 띠 (참고 이미지 3) | 웜그레이 / 라임·옐로우 |
| 오리엔탈 | 연기 리본 | 소용돌이치며 풀리는 여러 가닥 리본과 끝의 페이즐리 컬 | 버건디 / 골드 |
| 그린/아쿠아틱 | 물결 파문 | 여러 지점에서 번지며 겹치는 물결 | 블루 / 민트 |

## 변수 → 모션 매핑

| 입력 | 모션 파라미터 |
|---|---|
| 계열 비중 | 레이어 구성(가장 높은 계열 = 기본 톤·주 모션), 바탕색 혼합, 확산 경계 모양 `r(θ)` |
| 농도 `c` | 채도(×0.5→1.15), 레이어 불투명도(0.35→1), 선 밀도·굵기(부채 선 수, 섬유 굵기, 리본 가닥 수), 낮으면 흐림 |
| 지속력 `l` | **모션 속도**(×1.6 → ×0.3, 오래갈수록 느림), 잔상 길이(섬유 길이, 꽃잎 잔상, 방울 꼬리, 남는 파문 수), 0.6 미만이면 선이 끊김 |
| 실라주 `s` | **반복 횟수**(섬유 48→264, 꽃 1→7, 방울 4→16, 리본 3→12, 파문 1→6), 확산 반경(0.22→0.80), 움직임 폭 |

반복 횟수가 정수로 바뀔 때는 마지막 요소가 소수부만큼 서서히 나타나므로 슬라이더를 움직여도 그래픽이 튀지 않습니다.

## 결정론

프레임 = `ScentRender.draw(canvas, computeParams(취향 벡터), t)`. 입력은 벡터와 시간 `t`뿐이며, 요소 배치에 쓰이는 값은 요소 번호의 정수 해시입니다.
같은 벡터·같은 `t`는 항상 같은 픽셀을 만들고, ↺ 버튼으로 `t = 0` 기준 프레임으로 돌아갈 수 있습니다.

## 코사인 유사도와의 단조 일치

계열 벡터의 코사인 유사도 `cos`에 대해 세 가지 그래픽 유사도가 모두 단조 증가하도록 설계했습니다.

- **형태**: 확산 경계 `r(θ) = 1 + A·Σ uᵢ·cos(kᵢθ + φᵢ)`가 모든 모션 레이어의 퍼지는 범위를 정합니다. 서로 다른 주파수의 코사인은 직교하므로 `‖r_a − r_b‖_RMS = A·√(1 − cos)`. 형태 유사도 = `1 − √(1 − cos)` (정확히 단조).
- **색상**: 계열 색 구성 비율 `pᵢ = uᵢ²`(합 = 1)로 모션 레이어 비중과 바탕색을 정합니다. 제곱이라 최대 계열이 기본 톤을 차지하면서도 연속입니다.
  두 색 구성의 바타차리야 계수 `Σ√(pᵢqᵢ) = Σuᵢvᵢ = cos` 이므로 색상 유사도는 코사인과 정확히 같습니다.
- **확산 범위**: 할로 경계 `ρ(θ) = R(s)·r(θ)`의 RMS 거리 기반. 실라주가 같으면 `R·A·√(1 − cos)`로 단조입니다.

화면 하단 "매핑 검증"에서 표본 400쌍의 산점도와 스피어만 ρ(= 1.0000)를 확인할 수 있고, `npm test`가 같은 성질을 검사합니다.

> 참고: 혼합된 **단일 평균 톤**의 OKLab 거리만 떼어 보면 코사인과 완전 단조가 아닙니다(5차원 → 3차원 색 공간 투영 때문, 스피어만 ≈ 0.55).
> 그래서 색상 유사도는 그래픽에 실제로 쓰인 색 구성(히스토그램) 기준으로 정의했습니다.

## 파일 구조

- `js/engine.js` — 순수 매핑 엔진 (벡터 → 파라미터, 유사도). 브라우저·Node 공용
- `js/render.js` — 모션 렌더러 (파라미터 + t → 프레임, 계열별 모션 5종)
- `js/app.js` — UI: 향수 목록, 슬라이더와 매핑 표시, 단일/비교/검증 보기, 재생·정지, URL 해시 공유
- `test/engine.test.js` — 결정론·평균·단조성·난수 부재 테스트

프리셋 향수는 설명을 위한 가상의 예시이며 실제 제품 데이터가 아닙니다.
