# Scent Vector — 향 취향 시각화 프로토타입

향수를 수치 벡터로 표현하고, 사용자가 쓴 향수 벡터의 **평균(취향 벡터)** 하나만으로 그래픽을 생성하는 결정론적 시스템입니다.
난수를 쓰지 않아 같은 벡터는 항상 같은 그래픽(같은 픽셀)을 만듭니다.

## 실행

빌드 없이 정적 파일로 동작합니다.

```bash
python3 -m http.server 8000   # 또는 npm start
# http://localhost:8000 접속 (index.html을 직접 열어도 동작)
npm test                      # 결정론·단조성 테스트 (Node 18+)
```

## 벡터 정의

| 성분 | 범위 | 의미 |
|---|---|---|
| `f = [플로럴, 우디, 오리엔탈, 시트러스, 그린/아쿠아틱]` | 각 0–1, 합 = 1 | 계열 비중 |
| `c` | 0–1 | 농도 (오 드 코롱 0 · EdT ⅓ · EdP ⅔ · 퍼퓸 1) |
| `l` | 0–1 | 지속력 |
| `s` | 0–1 | 실라주(확산력) |

취향 벡터 = 사용한 향수 벡터들의 산술 평균 (`ScentEngine.meanVector`). 계열 비중은 평균해도 합이 1로 유지됩니다.

## 고정 매핑 규칙

| 입력 | 시각 요소 |
|---|---|
| 가장 높은 계열 | 기본 톤. 플로럴=연핑크·라벤더, 우디=브라운·카키, 오리엔탈=버건디·골드, 시트러스=옐로우·라임, 그린/아쿠아틱=민트·블루 |
| 계열 방향 `u = f/‖f‖` | 형태 `r(θ) = 1 + A·Σ uᵢ·cos(kᵢθ + φᵢ)` (플로럴 5엽, 우디 3엽, 오리엔탈 2엽, 시트러스 7엽, 그린 4엽) |
| 농도 `c` | 높을수록 채도(×0.5→1.15)·레이어 불투명도(0.16→0.88)↑, 낮을수록 흐림(blur)↑·옅어짐 |
| 지속력 `l` | 길수록 회전하며 번지는 그라데이션 잔상 트레일(0→12개), 짧을수록 끊어진 점선과 또렷한 윤곽 |
| 실라주 `s` | 확산 반경(0.20→0.45), 입자 수(70→590), 응축 지수 — 약하면 중심에 응축 |

모든 파라미터는 연속 함수입니다(정수 개수 요소는 마지막 요소의 부분 알파로 보간). 그래서 가까운 벡터는 가까운 그래픽을 만듭니다.

## 코사인 유사도와의 단조 일치

계열 벡터의 코사인 유사도 `cos`에 대해 세 가지 그래픽 유사도가 모두 단조 증가하도록 설계했습니다.

- **형태**: 서로 다른 주파수의 코사인은 직교하므로 `‖r_a − r_b‖_RMS = A·√(1 − cos)`. 형태 유사도 = `1 − √(1 − cos)` (정확히 단조).
- **색상**: 계열 색 구성 비율 `pᵢ = uᵢ²`(합 = 1)로 입자·잔상 색을 배분하고 기본 톤을 혼합합니다. 제곱이라 최대 계열이 기본 톤을 차지하면서도 연속입니다.
  두 색 구성의 바타차리야 계수 `Σ√(pᵢqᵢ) = Σuᵢvᵢ = cos` 이므로 색상 유사도는 코사인과 정확히 같습니다.
- **확산 범위**: 할로 경계 `ρ(θ) = R(s)·r(θ)`의 RMS 거리 기반. 실라주가 같으면 `R·A·√(1 − cos)`로 단조입니다.

화면 하단 "매핑 검증"에서 표본 400쌍의 산점도와 스피어만 ρ(= 1.0000)를 확인할 수 있고, `npm test`가 같은 성질을 검사합니다.

> 참고: 혼합된 **단일 평균 톤**의 OKLab 거리만 떼어 보면 코사인과 완전 단조가 아닙니다(5차원 → 3차원 색 공간 투영 때문, 스피어만 ≈ 0.55).
> 그래서 색상 유사도는 그래픽에 실제로 쓰인 색 구성(히스토그램) 기준으로 정의했습니다.

## 파일 구조

- `js/engine.js` — 순수 매핑 엔진 (벡터 → 파라미터, 유사도). 브라우저·Node 공용
- `js/render.js` — Canvas 렌더러 (파라미터 → 그림, 내부 해상도 640×640 고정)
- `js/app.js` — UI: 향수 목록, 슬라이더, 최대 4개 프로필 비교, 유사도 표, 검증 차트, URL 해시 공유
- `test/engine.test.js` — 결정론·평균·단조성·난수 부재 테스트

프리셋 향수는 설명을 위한 가상의 예시이며 실제 제품 데이터가 아닙니다.
